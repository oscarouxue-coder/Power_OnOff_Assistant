## 已完成

- 深青色全局顶栏与项目侧栏、浅色工作区及白色卡片；业务导航在项目内部，原全部模块入口、危险确认和停止控制保留。
- 默认只读总览：四项真实统计、卡片/列表切换和本机偏好保存、运行中/其它项目分组、搜索、滚动和详情进入。总览不创建任务计数或第二套执行器。
- 详情采用中央运行卡片/原通道概览、右侧配置摘要/原表单与通道选择、底部项目日志。默认收起详细配置；全部控件保留，滚动查看VLAN/COM，窄窗口导航自动换行。
- 原项目日志增加拖动高度、折叠、原生自动滚动勾选和有界显示；完整文件继续按原写入链路保存，已有隐藏/摘要保持。首页显示独立有界工作区事件，未冒称跨项目全部原始日志。
- 状态来自ProjectStatusService及原通道快照；只汇总已确认批次的通道，排除旧页面保留的其它批次结果。各通道轮次不同步展示范围，不取随意平均值。未知不算正常，任务时间只显示已有开始时间，不伪造有效时长。
- 切页仍使用pack/pack_forget，后台任务不受影响；延迟选择事件不能把总览跳回详情。现有ProjectViewFrame负责回调清理，无新增业务线程、订阅或周期调度器。
