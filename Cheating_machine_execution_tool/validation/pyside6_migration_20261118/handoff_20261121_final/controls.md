# 第一阶段 Qt 本机与远程控制面核查

2026-11-21，本表按当前候选的菜单绑定、服务调用和已执行的测试核对 Phase 5。现场模型、平台账号、远端实例、串口及 DUT 待现场。此次仅审计入口并运行临时目录内的网关路由夹具。

| 原功能 | Qt 候选及当前证据 | 可以继续做的本机工作与验收条件 |
|---|---|---|
| 导入的平台配置选择、软件更新、模型连接、消息试发 | 已有 Qt 菜单或业务设置入口。导入候选选择检查身份与版本，选用禁用配置后保留操作反馈；模型测试和试发有替换客户端的原生测试 | 复用候选三档结果。真实平台回执、模型连通和目标机实际下载按各自现场条件验收 |
| 任务核实、历史记录 | 原 GUI 未知任务和持久化 Job 各有本机核实入口。可在任务历史中复核任务范围、记录状态及事件 | 核对旧库、不同项目同名任务、过期核实、取消、已终止任务。任务记录的历史状态与当下资源租约需分别观察 |
| 本地会话、报告和案例 | Qt 支持普通问答、选择/改名/批量删除历史、报告与留存证据。原 Tk “查看本会话排查进展”读取会话中持久化的目标、步骤、检查、观察及结束原因，Qt 会话菜单目前缺该只读入口 | **优先补齐**项目和会话绑定的留存进展视图。用具有步骤的旧会话、空记录、关闭后重开、切换项目和会话的夹具验证；读取过程应能在断网时完成。命中旧会话的最近一次记录，只显示其已保存字段。该项无需实验室 |
| 远程可访问项目 | Tk 项目/设置菜单列出已打开项目，用本机确认后调用 `set_remote_projects`。Qt 有导入配置选择，尚缺原授权范围窗口。共享服务会更新授权文件，撤销相应路由并保留已准入任务 | 可先从 `workspace.remote_projects` 和已打开项目身份生成只读范围，在双项目临时目录核对已选/未选、关闭和重开。原可写入口需补齐快照绑定、确认期间名单变化、授权撤销后旧会话拒用和已有任务继续等回归 |
| 多实例/统一网关 | Tk 有本机实例与网关页，含状态、实例详情、复制实例 ID 和显式管理动作。Qt 项目菜单尚无该入口。共享的 `management().status()` 可读取当前模式、槽位、实例/运行 ID、连接与网关状态，底层会短时检查主机锁 | 可先做后台只读状态展示和复制已知 ID。模拟无实例、处理中、外部运行、启动失败、未连接，核对显示与刷新、关闭及迟到结果。原控制器注册可以触发已配置网关启动，读取页面不得调用注册。配对、撤销、启停的真实验收另需授权的两端实例和平台身份 |
| 会话权限、审批、受控扩展、实时诊断 | 旧 Tk 有按会话权限、审批及业务任务/扩展管理。Qt 支持留存材料的分析和消息停止，尚缺原权限编辑、审批及对应实时诊断控制面 | 可先核对旧会话保存的权限显示、任务及扩展的只读摘要。旧偏好与本轮有效授权须分别呈现，旧授权失效、重启、同名不同会话应有回归。带写入、接入或授权的操作另按原身份与审批服务实施，正式设备、平台和模型链路需要相应实验室条件 |
