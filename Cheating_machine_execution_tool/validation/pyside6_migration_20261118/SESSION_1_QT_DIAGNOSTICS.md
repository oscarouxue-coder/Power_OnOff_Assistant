## 2. 接入当前批次证据

- 复用原证据缓存、日志有界尾读、脱敏和批量入库。按项目、诊断批次、通道及快照中的目标身份核对来源；继续追问能取得新记录，重复刷新沿用原去重行为。遇到配置已变、快照缺失或来源不明，保留既有会话材料，并给出可理解的反馈。
- 从 Qt 选择通道和发送问题两个真实入口验证。当前通道、同一项目其他通道、另一项目同号通道、旧批次、报告接手及远程历史分别设置不同标记。旧会话只能读取原有留存材料，模型消息不能指定本地文件或其他端口。采用原服务对证据来源、故障时间和读取时间的标识。
- 保留普通问答、普通电脑排障和连续电脑诊断的原偏好。验证自然语言切换、明确通道快捷路径、无效目标澄清、取消及迟到回复、发送失败恢复草稿和保留新输入。网关继续受理项目列表及切换项目，对读串口、停止等业务消息明确回绝。测试使用模拟模型、模拟网关与模拟设备。
