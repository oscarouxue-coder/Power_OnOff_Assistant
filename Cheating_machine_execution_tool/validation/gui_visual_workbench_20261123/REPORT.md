# Qt 工作台美化首批接入

2026-11-23，按已展示的样式将总览、自动开关机、全业务老化接入正式源码工作台。正常启动使用正式入口，独立预览继续提供同一组模拟快照的前后对照。

## 正式布局

- 总览使用新版项目卡片、紧凑统计卡和实时资源摘要。资源摘要取原工作区采样，展开后保留全部系统指标。
- 开关机在首屏呈现原轮次进度、异常摘要、通道及最近阶段。圆环与横条使用同一批次的轮次数据。老化页按监测时长、业务健康、逐台在线和业务观测分区。
- 窄窗默认收起侧栏和日志，使用原控件可重新展开。用户手动展开、收起或拖动后，在本会话保留选择。原操作、日志归属、项目绑定和数据来源沿用。

以下为正式窗口类使用隔离模拟快照的 1440 × 900 源码版截图。[总览](formal-overview.png) · [自动开关机](formal-power.png) · [全业务老化](formal-aging.png)

## 验证

- Windows 私有桌面以锁定 Qt 解释器运行工作台、专项及项目向导相关用例，100%、125%、150% 各通过 23 项。核对 800 × 440 窗口、卡片不重叠、起停按钮可达、快照刷新、轮次一致、老化状态和日志范围，以及手动展开在缩放后保持。最终截图和两类挂测展示另经每档 5 项复核。[专项结果](focused-results.json) · [展示复核](presentation-results.json)
- 初次扩大运行在项目向导用例发现正式轮次区标题缺少测试类型。补回「自动开关机」后，将该向导用例纳入最终三档专项。初次记录对应修复前的源码。[旧记录](full-1.txt)
- 局部编译、启动契约和能力覆盖通过。本轮未运行仓库完整基线。截图与隔离测试使用模拟项目和设备服务，现场操作员目视复验另行登记。
