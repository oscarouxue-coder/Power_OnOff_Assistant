def modify_incom_ipfilter_rule(self, instance_id, description=None, source_ip=None, dest_ip=None, source_port=None, dest_port=None, ip_version=None, protocol=None, x_sdmc_direction=1, source_interface=None): ¶

修改已存在的 IPFilter 规则。 参数： - instance_id: 规则实例ID（int 或 str） - description: 描述信息（可选） - source_ip: 源 IP 地址（可选） - dest_ip: 目的 IP 地址（可选） - source_port: 源端口（可选） - dest_port: 目的端口（可选） - ip_version: IP 版本（可选） - protocol: 协议（可选） - x_sdmc_direction: 固定为1，修改income方向的规则 - source_interface: 类似 "2_INTERNET_R_VID_200"，会自动转换为 "Device.IP.Interface.2"（可选） 返回： - True 表示设置成功 - 抛出异常表示失败

def modify_outcom_ipfilter_rule(self, instance_id, description, ip_version, protocol, src_ip, src_port, dst_ip, dst_port): ¶

修改指定编号的 IPFilter 规则，X_SDMC_direction 默认固定为 "0"。 参数： - instance_id (int): 要修改的规则编号，如 1 表示 Rule.1 - description (str): 规则描述 - ip_version (int): IP 版本（4 或 6） - protocol (str): 协议类型，如 "TCP"、"UDP" - src_ip (str): 源 IP 地址 - src_port (int): 源端口 - dst_ip (str): 目的 IP 地址 - dst_port (int): 目的端口 返回： - True 表示成功，否则抛出异常
