def Ubus_Management_cwmp_set_TR069_parameters(self, **kwargs): ¶

功能描述：

设置 CWMP (TR069) 参数

参数：

Url：ACS服务器地址 Username：正向连接的用户名，默认 hgw,对应页面 ACS Account Password：正向连接的密码，默认 hgw,对应页面 ACS Password Period_Inform_Enable：周期上报使能开关，默认开启：1，关闭：0 Periodic_Inform_Interval：周期上报间隔，默认86400s HTTP_Connection_Request_Enable：默认开启:1,关闭:0,对应页面Connection Request Connection_Request_Username:默认itms,对应页面 User Name Connection_Request_Password:默认 itms,对应页面 Password Certificate_Enable:默认关闭:0,开启:1,对应页面 Enable Certificate

返回值：

ret:设置TR069参数的UBUS 接口返回值

Example: | ${ret} | Ubus_set_TR069_parameters | | ${ret} | Ubus_set_TR069_parameters | Period_Inform_Enable=Fasle

def Ubus_Management_cwmp_TR069_inform(self, inform_times=10): ¶

功能描述：

TR069 Inform，并获取Inform状态，success后退出返回结果，如果不是 success 则持续等待重新Inform并获取结果

入参：

inform_times：inform 失败后重试次数

返回值：

tuple: (最终状态, 结果代码) 状态值: "success"、"timeout"、"error" 结果代码: 对应各种错误码或成功码(10_success)
