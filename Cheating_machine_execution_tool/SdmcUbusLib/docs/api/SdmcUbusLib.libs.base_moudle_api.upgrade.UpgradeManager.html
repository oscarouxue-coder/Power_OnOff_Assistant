def unit_test(self, device_url, local_file_path, device_save_path): ¶

功能描述：执行一次完整的固件升级单元测试流程。步骤包括：

  • 获取本地固件的目标软件版本和硬件版本；

  • 登录设备；

  • 上传固件并触发升级；

  • 等待设备重启上线；

  • 对比设备升级后的版本是否与期望一致。

    参数： | device_url | 上传接口 URL（如 http://192.168.1.1/cgi-bin/upload.cgi） | | local_file_path | 本地固件文件路径（如 /tmp/fw.bin） | | device_save_path | 上传到设备后的保存路径（如 /tmp/fw.bin） |

    返回： | 返回值类型 | 说明 | | None | 无返回值，如失败会抛出异常 |

    异常： | RuntimeError | 登录失败或升级失败等错误 | | TimeoutError | 等待设备上线超时 | | AssertionError | 版本校验失败，实际版本与期望不一致 |

    Example: | Unit Test | http://192.168.1.1/cgi-bin/upload.cgi | /tmp/fw.bin | /tmp/fw.bin |
