def get_wifi_band_map(self, wireless_output): ¶

【功能描述】 解析无线配置，识别各 wifi-device 对应的频段（2.4G / 5G）。 【入参】 wireless_output : str 从命令 `cat /etc/config/wireless | grep wifi-device` 获取的输出内容。 【返回值】 dict : 返回各频段对应的设备名称，格式示例： { "2.4G": "phy0", "5G": "phy1" } 如果某个频段没有设备，则不包含该键。 【示例】 Example: | get_wifi_band_map | wireless_output=<输出字符串> | 返回示例: {'2.4G': 'phy0', '5G': 'phy1'}

def parse_telnet_output(self, output: str, cmd: str): ¶

【功能描述】 从 telnet 返回的字符串中提取有效结果，去掉命令行和提示符行。 【入参】 output : str telnet 执行命令返回的原始字符串 cmd : str 执行的命令，用于过滤命令行本身 【返回值】 str : 返回命令实际输出内容（去掉提示符和命令本身） 如果解析失败或为空，返回 None。 【示例】 Example: | parse_telnet_output | output=<原始字符串> | cmd=<命令> | 返回示例: "US"
