# Qt components in this validation package

The Qt build uses unmodified dynamic libraries and Python extensions from PySide6-Essentials 6.8.3 and shiboken6 6.8.3. The Windows plugin and libraries are unpacked alongside the application. A compatible replacement must use the same architecture, interfaces and plugin layout. Retain the original directory to restore the shipped binaries.

The Qt libraries and Qt for Python components have LGPLv3/GPLv3 or commercial licensing options. The accompanying GPL and LGPL texts come from the Qt Base 6.8.3 tag. The license records supplied in the two Python wheels are retained beside these files. Qt and Qt for Python include separately licensed third-party components. Consult their respective component notices.
