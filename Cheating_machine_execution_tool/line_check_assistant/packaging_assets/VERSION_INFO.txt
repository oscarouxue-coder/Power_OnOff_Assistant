LineCheckAssistant 便携版版本说明
==================================

版本：V1.2.7
发布日期：2026-11-05

本版本更新：
1. 串口日志每个标签增加“×”，可停止并关闭指定标签，保留已保存日志，其它串口
   继续工作；自动升级占用期间禁止关闭并提示原因。
2. 关闭最后一个串口标签后窗口保留，可从主界面串口日志入口恢复标签，再打开全部。
3. 全流程第6项读取串口日志窗口当前目录，首次打开前恢复上次有效目录；选择新目录
   后立即同步未运行的全流程窗口及执行确认。已有监控继续写入原文件。

沿用网卡及 WiFi 功能：
1. 主界面增加“显示所有网卡和串口”选项，可选择本机全部识别网卡和实际串口；
   关闭后恢复分组显示并保留当前选择，每次启动默认关闭。
2. 正式 Telnet 开关机测试 WiFi 支持“分别验证频段”和“双频合一”，默认自动
   识别认证方式，保留高级手动设置；核对样机 SSID/BSSID、实际频段和认证，
   连续稳定连接 2 秒后通过。临时连接不保存或清理用户已有无线配置。
3. 新增可选无线 Ping，默认关闭，支持 IPv4 或域名；通过所选无线接口查询和
   发包，每项 4 包、至少 1 个回复通过，日志显示连接、丢包及延迟结果。
4. 保留 WiFi 按通道排队、停止及失败续跑；连接或无线接口变化时重新判定结果。
5. 修复左侧“选择测试通道”列表空白处点击会误选末行或切换启用状态的问题。

沿用项目名称及 WiFi 排队功能：
1. 主界面工具栏醒目显示“项目信息”中已保存的项目名称，保存、重新加载和打开
   配置后自动刷新；长名称自动省略，悬停可查看完整名称。
2. 正式 Telnet 开关机测试的 WiFi 检查按通道先后排队，每个通道连续检查双频；
   排队、连接、重试和信息查询支持停止，取消后显示已停止，不误记为 WiFi 失败。
3. 失败通道续跑首次进入 WiFi 检查时重新获取信息；每次执行或续跑首次读取后，
   主日志显示一次双频 SSID 和密码摘要（明文），并记录排队、连接和检查结果。

沿用初始化断电规则：
1. 正式开关机测试初始化只对本次已勾选通道逐个发送关闭帧，不再广播全通道断电，
   避免影响其它通道设备；Telnet 和 SSH 测试均采用此规则。
2. 启动确认列出实际通道，执行日志记录目标通道和实际电源帧；初始化中停止或
   下发异常时终止，不继续启动测试，也不自动恢复已断电通道。
3. 失败通道续跑继续跳过初始化断电，保持单通道恢复规则。

沿用版本校验：
1. 开关机开始前版本校验支持按需执行：当前测试方案“项目信息”中的软件版本、
   内部软件版本、ONU 软件编译时间全部留空并保存后，跳过开始前版本校验。
   首尾空白不计入内容，项目名称不影响是否校验。
2. 三项版本只填写一项或两项时，提示缺少字段并阻止启动；全部填写时保持严格
   校验，任一版本不一致或查询失败均阻止启动开关机测试。
3. 失败通道“从失败轮次继续”采用相同规则；确认提示及执行日志明确说明跳过
   或执行版本校验，仍核对原配置，并只恢复目标通道的剩余轮次。
4. 配置文件缺失、不可读或格式错误时明确报错，不会误判为空版本而跳过校验。
5. 修复 Python 3.9 环境下检查更新模型导致的源码启动兼容问题。

沿用功能：
- 网卡名称检查及确认改名，支持 2–254 数字尾号（非网关地址），保留通道和 COM 对应关系。
- 主界面检查更新与便携包下载，支持进度、取消和 SHA256 校验。
- 样机升级安全停止、CMS 登录修复、C600 VLAN 转换与 ONU 命令只读预览。
- 测试项执行、失败通道续跑、串口日志、DUT 配置及消息推送。

下载与使用：
- 下载 LineCheckAssistant_portable.zip 并完整解压，再运行其中的 LineCheckAssistant.exe；
  首次运行建议以管理员身份运行。
- 新包配置已脱敏，使用前填写现场网络、COM、设备账号及测试方案。
- 换版前结束测试并退出旧程序，备份旧目录及 Auto_power_on_off_tool/config；
  将新包解压到另一个目录后迁移配置，不要用默认配置覆盖旧目录。
- 下载同次发布的 LineCheckAssistant_portable.zip.sha256.txt 核对 ZIP 下载完整性。
  版本说明、第三方声明及 EXE 校验文件均包含在 ZIP 内。

- 150% 字体缩放时建议窗口保持 1200 像素以上宽度或最大化。
