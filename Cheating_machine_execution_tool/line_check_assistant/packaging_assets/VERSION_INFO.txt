LineCheckAssistant 便携版版本说明
==================================

版本：V1.2.3
发布日期：2026-10-17

本版本更新：
1. 开关机开始前版本校验支持按需执行：当前测试方案“项目信息”中的软件版本、
   内部软件版本、ONU 软件编译时间全部留空并保存后，跳过开始前版本校验。
   首尾空白不计入内容，项目名称不影响是否校验。
2. 三项版本只填写一项或两项时，提示缺少字段并阻止启动；全部填写时保持严格
   校验，任一版本不一致或查询失败均阻止启动开关机测试。
3. 失败通道“从失败轮次继续”采用相同规则；确认提示及执行日志明确说明跳过
   或执行版本校验，仍核对原配置，并只恢复目标通道的剩余轮次。
4. 配置文件缺失、不可读或格式错误时明确报错，不会误判为空版本而跳过校验。
5. 修复 Python 3.9 环境下检查更新模型导致的源码启动兼容问题。

沿用功能：
- 网卡名称检查及确认改名，支持 2–254 数字尾号（非网关地址），保留通道和 COM 对应关系。
- 主界面检查更新与便携包下载，支持进度、取消和 SHA256 校验。
- 样机升级安全停止、CMS 登录修复、C600 VLAN 转换与 ONU 命令只读预览。
- 测试项执行、失败通道续跑、串口日志、DUT 配置及消息推送。

下载与使用：
- 推荐下载 LineCheckAssistant_portable.zip 并完整解压，再运行程序。
- 仅在已有配套配置时单独使用 LineCheckAssistant.exe；首次运行建议以管理员身份运行。
- 新包配置已脱敏，使用前填写现场网络、COM、设备账号及测试方案。
- 换版前结束测试并退出旧程序，备份旧目录及 Auto_power_on_off_tool/config；
  将新包解压到另一个目录后迁移配置，不要用默认配置覆盖旧目录。
- 可使用同次发布的 SHA256 校验文件核对下载完整性。
