LineCheckAssistant 便携版版本说明
==================================

版本：V1.2.2
发布日期：2026-10-16

本版本更新：
1. 选择非数字结尾的网卡时提示修改名称，可选择接受或取消建议。
2. 接受后输入新名称并点击“确认修改”，由软件完成 Windows 网卡重命名。
   新名称须以 2–254 的数字结尾（非网关地址），例如 VLAN101、以太网101。
3. 改名成功自动刷新网卡、更新通道引用、PC 静态 IP 和相关目标预览，
   保留原通道勾选和已有 COM 对应关系；失败、取消及配置保存问题均有提示。
4. 修改前检查管理员权限和设备任务状态；后台执行并核实结果，防止重复提交。

沿用功能：
- 主界面检查更新与便携包下载，支持进度、取消和 SHA256 校验。
- 样机升级安全停止、CMS 登录修复、C600 VLAN 转换与 ONU 命令只读预览。
- 测试项执行、失败通道续跑、串口日志、DUT 配置及消息推送。

下载与使用：
- 推荐下载 LineCheckAssistant_portable.zip 并完整解压，再运行程序。
- 仅在已有配套配置时单独使用 LineCheckAssistant.exe；首次运行建议以管理员身份运行。
- 新包配置已脱敏，使用前填写现场网络、COM、设备账号及测试方案。
- 换版前结束测试并退出旧程序，备份旧目录及 Auto_power_on_off_tool/config；
  将新包解压到另一个目录后迁移配置，不要用默认配置覆盖旧目录。
- 可使用同次发布的 SHA256 校验文件核对下载完整性。
