LineCheckAssistant 便携版版本说明
==================================

版本：V1.1.3
发布日期：2026-09-20

本版本内容：
1. 本次按当前源码重新打包，包含批量 ONU 注册及逐目标手填 ONU ID 保留修复。
2. 新增测试项单次预备测试，命令仅执行一次，结果在主日志显示并保存。
3. 新增 SDMC 进入 Boot 方式和 web打开网关升级路径；Web 提交前按所选
   VLAN 出口等待升级表单就绪，单次提交后固定等待30秒接原收尾流程。
4. 修复启动日志被误判为 Boot 提示，兼容无 HTTP 响应头的升级页面，
   补充浏览器与代理超时阶段日志。

沿用内容：
1. 新增 C300/C600 ONU 类型模板和 DBA 模板的只读查询入口。
2. 查询结果统一显示为“模板名（值）”：ONU 类型模板显示 PON 类型值，
   DBA 模板显示速率值；不再显示“PON类型：”或“速率：”标签。
3. ONU 类型模板输入框仍可手动填写，兼容现场自定义模板；实际下发时仍只
   使用模板名。
4. Windows 应用图标更新为“网络拓扑诊断”图形，突出网络通信产品的链路
   管理和测试定位；不改变任何设备业务或配置行为。

验证范围：
- C600 两台手填 ONU ID 3/4 保留、预备测试基本执行及日志已有负责人
  确认；其它组合、停止与异常专项仍以项目验收记录为准。
- SDMC、Web升级及最新就绪等待修复仍待 Windows 可见界面、真实样机
  升级和多通道验收。本次重新打包不扩大既有验收结论。
- 本次构建不在打包电脑启动生成的 EXE；目标电脑启动需另行验证。
- C300/C600 模板查询结果的显示已由项目负责人确认。
- 本说明不代表整台 OLT 未注册 ONU 查询、ONU 注册/删除、升级或其它真实
  设备流程均已完成现场验收；请按实际工作范围单独核对。

使用提示：
- 请完整解压便携 ZIP 后再运行 LineCheckAssistant.exe。
- 发布包配置已脱敏；在目标电脑使用前需重新填写现场网络和设备配置。
