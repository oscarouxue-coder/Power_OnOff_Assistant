LineCheckAssistant 便携版版本说明
==================================

版本：V1.2.1
发布日期：2026-10-16

本版本内容：
1. 主界面新增“检查更新”，手动查询 GitHub 最新正式版本、显示更新说明，
   可下载完整便携 ZIP；支持进度、取消、SHA256/大小/ZIP格式检查和打开目录。
   下载后由操作员退出旧版并手动换版，配置须先备份再迁移。
2. 更新检查/下载在后台运行；关闭窗口取消本次任务，退出时等待临时文件清理。
   工具栏在窄窗口下换行，保留管理员权限提示与两个刷新按钮的顺序。
3. 样机升级新增安全停止，覆盖页面及三种全包升级并与全流程停止联动；
   已开始的传输安全收尾，停止后不再发起后续重试、reset或恢复出厂。
4. 修复CMS成功提示符为 > 时的初始登录错位；保留其它提示符的原有登录路径。
5. 打包兼容当前PyInstaller 6的Tcl/Tk数据目录，同时保留旧版tcl/tk资源。
   发布同时提供便携ZIP的独立SHA256文件，供程序内下载校验使用。

沿用V1.1.4内容：
1. C600业务映射支持 ServiceID,ONU侧VLAN,网络侧VLAN，兼容原两列。
   普通数据及语音335、IPTV600、TR06950均支持一对一转换，资源按网络侧
   VLAN分层。例如 2,111,171 表示ONU VLAN111进入网络VLAN171。
2. IPTV转换同步配置ONU侧MVLAN及目标VPort的组播转换，OLT侧MVLAN仍为600；
   不修改全局组播转换表。实际执行和只读回读使用同一确认快照。
3. ONU确认执行页改为只读，移除编辑、校验、恢复、目标下拉框及预览统计行。
   多台ONU在同一预览框内按执行顺序分段显示，标题不下发OLT。
4. 测试项配置补齐“登录后命令”保存与新版执行；成功提示符严格为 > 时
   发送一次，空值只回车，发送后等待1秒。命令输入框与提示符输入框等宽。
5. 失败通道支持右键从失败轮次继续；正常轮次恢复绿色状态，保留失败历史。
   Telnet连接/命令异常及Ping错误写入对应通道和轮次的重试/失败历史。
6. 钉钉通知使用测试方案磁盘已保存的项目名称，未保存的页面修改不影响发送。

沿用内容：
0. 保留批量ONU逐目标手填ID、测试项单次预备测试、SDMC进入Boot及
   web打开网关升级路径；升级表单就绪等待、单次提交和原收尾流程保持。
1. 新增 C300/C600 ONU 类型模板和 DBA 模板的只读查询入口。
2. 查询结果统一显示为“模板名（值）”：ONU 类型模板显示 PON 类型值，
   DBA 模板显示速率值；不再显示“PON类型：”或“速率：”标签。
3. ONU 类型模板输入框仍可手动填写，兼容现场自定义模板；实际下发时仍只
   使用模板名。
4. Windows 应用图标更新为“网络拓扑诊断”图形，突出网络通信产品的链路
   管理和测试定位；不改变任何设备业务或配置行为。

验证范围：
- 本版包含85个源码编译/覆盖及173项强制回归；全量测试结果见发布记录。
  自动化与归档检查不代表完整Windows界面、目标电脑启动或真实设备验收。
- C600新增VLAN转换、IPTV目标VPort组播命令的现场版本兼容性、WAN地址、
  双向通信、持续播放与切台仍待负责人确认；确认页最终布局待Windows复验。
- 登录后命令、失败通道续跑/状态/历史及钉钉实际收信新增范围仍以
  ACCEPTANCE_BASELINE和项目负责人现场结论为准。
- C600 两台手填 ONU ID 3/4 保留、预备测试基本执行及日志已有负责人
  确认；其它组合、停止与异常专项仍以项目验收记录为准。
- SDMC、Web升级及最新就绪等待修复仍待 Windows 可见界面、真实样机
  升级和多通道验收。本次重新打包不扩大既有验收结论。
- 本次构建不在打包电脑启动生成的 EXE；目标电脑启动需另行验证。
- C300/C600 模板查询结果的显示已由项目负责人确认。
- 本说明不代表整台 OLT 未注册 ONU 查询、ONU 注册/删除、升级或其它真实
  设备流程均已完成现场验收；请按实际工作范围单独核对。

使用提示：
- 请完整解压便携 ZIP 后再运行 LineCheckAssistant.exe。
- 发布包配置已脱敏；在目标电脑使用前需重新填写现场网络和设备配置。
- 手动换版请先备份旧便携目录及config，将新ZIP完整解压到新目录，按说明
  迁移需要保留的本机INI/测试方案，不要用默认配置覆盖旧目录。
