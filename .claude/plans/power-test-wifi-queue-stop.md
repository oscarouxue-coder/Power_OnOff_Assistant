# 开关机测试 WiFi 排队与停止优化

2026-10-30：用户已明确要求按计划实施；仅源码，不打包、不提交。

- 每个正式 Telnet 测试子进程一个 FIFO 调度器；按通道持有使用权，连续完成启用的 2.4G/5G，成功、失败、异常和取消都释放。
- 排队、连接轮询和重试等待可停止；交接和驱动操作前后检查停止。取消不生成设备失败通知、不推进轮次、不进入下一频段或后续 Ping；保留外层10秒终止兜底。
- 保持4次连接尝试、每次约20秒、间隔10秒；不修改网卡、认证、连接成功判据或INI。保留首次实际WiFi阶段读取、单次执行缓存，续跑重新读取。
- 主日志保留排队、每10秒等待提示、占用、动作、结果、跳过、取消和释放。用户实施中补充允许明文密码：每次通道执行/续跑首次读取后显示一次双频SSID与密码摘要；原始回显仍不重复输出，其它敏感日志过滤保持。
- 新调度在service，既有连接接口增加可选停止/日志参数；旧GUI不接入新调度，SSH路径不扩展WiFi；不搬迁电源和其它测试项。
- 模拟网卡验证并发、停止竞态、重试、释放、续跑、日志与密码隐藏；完整基线通过后记录结果。负责人另做Windows源码版和真实双通道复验。
- 回退边界：整体回退本轮WiFi调度、可选连接参数、取消消息/UI状态及对应文档测试；保留工作区原有V1.2.4发布改动。
