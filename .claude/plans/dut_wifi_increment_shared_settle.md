# DUT WiFi递增批次统一稳定等待

## 目标

- 多台DUT开启“SSID递增”时，先完成全部目标的WiFi参数下发，仅由批次最后一台统一等待60秒。
- 统一等待结束后仍逐台重新登录并回读校验，不能因减少等待而省略任何目标的结果确认。
- 单台配置、未开启SSID递增的批量配置继续保持每台下发后等待60秒再回读的既有行为。

## 分层

- `src/core/dut_wifi_config.py`：拆分“下发”和“回读校验”协议切片；原`configure_wifi`仍组合两阶段并保留单台60秒等待。
- `src/services/dut_advanced_config_service.py`：仅在多台SSID递增批次中编排“全部下发 → 一次可停止的60秒等待 → 全部回读”。
- `line_check_assistant/app.py`：把SSID递增且目标数大于1的批次标记传给service，并在确认/执行日志说明等待规则。
- `tests/`：覆盖核心分阶段协议、批次仅等待一次、最后目标日志归属、逐台回读及普通批次兼容。

## 异常与停止

- 下发失败的DUT不进入回读阶段，但不阻断其它DUT；统一等待只在至少一台下发成功时执行。
- 等待期间点击停止应立即结束等待，已下发但未回读的目标明确标记为停止，不能宣告配置成功。
- 回读失败按目标独立记录，最终批次结果仍按原目标顺序返回。
