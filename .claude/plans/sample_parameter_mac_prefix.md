# 批量参数表MAC前缀自定义

## 目标

- 在“生成批量参数表”窗口增加MAC前6位输入行。
- 用户输入必须是6个十六进制字符；兼容冒号或短横线分隔，输出统一为大写冒号格式。
- 每台MAC后6位随机生成十六进制字符，同批保持唯一。
- 保持2.4G/5G SSID后缀取本机MAC末4位的已验收规则。

## 实施步骤

1. 为参数生成模板增加MAC前缀字段，在核心层完成长度、十六进制和单播校验。
2. 使用用户前缀生成同批MAC，为每台追加唯一的3字节随机后缀。
3. 增加UI输入行、执行日志、核心与UI接线测试，并纳入强制基线。
4. 同步README、项目状态、验收基线和开发日志。
5. 执行专项测试、`python scripts/verify_baseline.py`与差异检查。
