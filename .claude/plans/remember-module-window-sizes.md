# 记住功能模块窗口宽高

## 已确认范围

- 为样机升级、写样机参数、ONU 注册、测试项配置和全流程执行保存关闭前的宽高，并在下次打开时恢复。
- 串口日志和 DUT 配置已分别具备窗口尺寸恢复，本轮不迁移或重写它们。
- 不保存窗口位置；首次打开继续沿用当前默认尺寸和相对主界面的居中显示。

## 不变边界

- 运行中禁止关闭、写参停止保护、测试项未保存修改确认、ONU 的本次 `write` 授权及所有设备流程保持原样。
- 仅在窗口最终允许关闭时记录尺寸；用户取消关闭或被运行状态拦截时不得写入。
- 保存值受窗口现有最小尺寸和当前屏幕尺寸约束，损坏或缺失状态安全回退默认值。

## 实施与验证

1. 在 `src/ui/` 新增独立的窗口尺寸状态读写模块，以用户目录 JSON 存储五个模块的宽高。
2. 在 `line_check_assistant/app.py` 装配该模块，并在五个窗口创建/关闭路径调用；`pipeline_window.py` 通过主程序提供的接口复用。
3. 增加状态读写、收敛和关闭前保存的单元测试，更新操作员说明、项目状态和开发记录。
4. 运行专项测试、`python scripts/verify_baseline.py` 与 `git diff --check`；不打包、不运行 EXE、不连接真实设备。
