# DUT配置与测试项配置窗口加载优化

## 目标

- 缩短点击“DUT配置”和“测试项配置”后，窗口客户区完整显示前的等待时间。
- 保留已通过现场验收的标准 `Toplevel` 生命周期与客户区尺寸刷新兜底。
- 不延迟业务配置读取，不改变各 Tab 字段、查询、保存与执行行为。

## 实施步骤

1. 用源码版 Windows Tk 计时确认两个入口的同步构建耗时与居中布局耗时。
2. 已知窗口尺寸时直接按该尺寸居中，避免弹出前强制刷新整棵复杂控件树。
3. 增加更早的首帧尺寸刷新，同时保留 120ms、360ms 两次已验收兜底刷新。
4. 补充专项测试、强制回归门禁及用户/项目/验收/开发记录。
5. 运行专项测试、强制基线与 Windows 源码计时复核。
