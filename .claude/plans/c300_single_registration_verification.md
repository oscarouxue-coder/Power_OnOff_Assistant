# C300 单台注册与真实输出验证

## 目标

- C300 与 C600 一样，每次只允许选择并注册一台 ONU。
- 保持两类 OLT 的 CLI、接口格式和解析器完全独立。
- 按真实 C300 只读输出补齐 ONU ID/SN 冲突检查以及注册、业务、状态的下发后验证。

## 实施

1. C300 查询结果改为单选，移除 C300 多选/全选语义；service 层同时拒绝两类 OLT 的多目标请求。
2. C300 下发前按目标 PON/ONU ID 查询 `baseinfo`，并用 `show gpon onu by sn` 做整台 OLT 的 SN 查重，再确认目标仍在未注册表。
3. C300 下发后分别核对 baseinfo/state/detail、T-CONT/GEM/VPort、service-port/remote service/mvlan；任何缺项或值不一致均判定失败。
4. 默认 C300 连接使用 OLT `172.18.18.151` 和源 IP `172.18.18.40`；C600 已知默认仍为 `172.18.18.152` 和 `172.33.5.35`，不把密码写入源码。
5. 增加真实输出样例的解析与编排回归，同步用户说明、状态、验收边界和开发日志，最后运行完整基线门禁。

## 验收边界

- 本轮真实设备操作仅完成 C300 只读命令核对，不下发配置、不执行 `write`、不删除 ONU。
- 自动化测试验证解析和编排，不等同于真实 C300 注册写入验收。
