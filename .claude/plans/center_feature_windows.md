# 功能窗口居中计划

## 目标

- 主界面功能入口打开的新窗口相对主界面居中，不再默认出现在屏幕左上角。
- 主程序位于副屏时仍以当前主界面为中心。
- 保留DUT窗口尺寸记忆、客户区首帧刷新和串口日志有效历史位置。

## 实现

1. 在UI工具层提供通用顶层窗口居中函数，根据主界面实际屏幕坐标和宽高计算子窗口位置。
2. 接入全流程执行、样机升级、写样机参数、ONU注册、测试项配置和DUT配置的首次创建路径。
3. 串口日志无历史位置或历史位置仍为左上角时居中；用户主动移动后的有效历史位置继续恢复。
4. 自动上/下电选择框改用同一居中函数，移除硬编码460×215位置估算。
5. DUT和测试项配置先居中，再执行已验收的客户区尺寸刷新，确保刷新后位置不漂移。

## 验证

- 单元测试覆盖居中坐标、主界面不在原点、串口历史位置保留和各入口接线。
- `python scripts\verify_baseline.py`。
- Windows桌面逐个点击截图中的功能入口，确认首次窗口位于当前主界面中央。
