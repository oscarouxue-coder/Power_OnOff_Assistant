# 串口日志文件名增加日期

## 目标

- 串口终端日志文件名由 `vlan名_COM口.log` 调整为 `vlan名_COM口_YYYYMMDD.log`。
- 示例：`vlan112_COM12_20260808.log`。

## 实施边界

1. 日期取打开该串口监控时的本机日期。
2. 手动打开单个串口、“打开全部”和全流程串口日志预启动共用同一个命名入口。
3. Tab 显示名称、VLAN 到 COM 映射、日志目录、串口参数和原始日志写入方式保持不变。
4. 同一天重新打开相同 VLAN/COM 时继续使用同名日志文件；下一日期打开时生成新文件名。

## 验证

- 固定日期验证 `vlan112 + COM12 + 2026-08-08` 生成 `vlan112_COM12_20260808.log`。
- 将命名测试纳入强制基线并执行 `python scripts\verify_baseline.py`。
