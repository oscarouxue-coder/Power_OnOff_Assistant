# 公共网卡准备按需复用

## 目标

所有会修改目标 VLAN 网卡的主程序流程执行前先只读检查启用状态、IPv4 地址和前缀长度。配置已完全满足要求时直接复用；仅修复不满足项；查询失败时回退既有完整准备流程。

## 边界

- 公共 `prepare_network_for_sample` 通过可选参数启用预检，默认行为不变。
- 线路检查、页面升级、全包升级 TFTP 网卡、写参用户/工厂模式切网、测试项执行、DUT Telnet/WAN/语音/TR069 配置和 WAN 查询均传入复用开关。
- 全包升级、写参和 DUT 等原本执行 `wait_for_bindable_ip` 的流程继续保留可绑定确认；Ping、HTTP/UBUS、Telnet 和 TFTP 传输的后续成功判据不变。
- TFTP 的独立网络准备改为复用公共能力，`Tftp指令` 与 `Tftp Put` 传输链路仍严格分离。

## 验证

- 已满足：不调用启用和静态 IP 设置，也不执行等待稳定延时。
- 已启用但地址不匹配：只设置静态 IP。
- 状态查询失败：启用、设置 IP 和两次稳定等待完整回退。
- 所有生产调用点均明确传入复用开关，公共函数默认值仍用于兼容和完整准备回归。
- 执行全量 `python scripts\verify_baseline.py` 和 `git diff --check`。
