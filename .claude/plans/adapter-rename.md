# 网卡名称提示与重命名

- 用户已确认实施：选择非数字结尾网卡时先恢复原选择，询问是否改名；接受后输入名称并确认，由软件修改 Windows 网卡名称。
- 新名称尾号为 2–254，界面明确提示“非网关地址”；不更改既有通道 IP 推导规则，不自动发现或配置系统网关。
- 分层：独立 ui 输入/后台队列窗口、service 校验/身份核实/引用同步、core 系统查询/单次重命名、models 身份与结果。app 只接入选择事件和 UI 回调。
- 改名前检查管理员和设备任务空闲；模态窗口阻止其它入口，后台单次执行，按 InterfaceGuid 回读，超时先核实、不盲目重试。
- 成功刷新候选与目标预览、更新通道引用及 PC IP并按原规则只保存启用通道。保留显式 COM；历史无显式 COM但原 VLAN 有有效映射时，将原映射保存为显式 COM，避免改名换口。其它字段不重新采集。
- 用户取消或系统失败不保存本次选择；系统成功而配置保存失败明确提示并保留新内存状态；身份回读不确定时禁止本窗口重复提交，提示人工核实后刷新。
- 回归包括所有分支、任务状态、字段保持、历史 COM 和独立 Windows Tk 模态/居中/响应；执行完整 verify_baseline。同步操作员说明、状态、验收基线和开发日志。
- 本轮不打包、不运行 EXE、不提交 Git；自动化全部模拟重命名，不修改真实网卡；完整主程序与空闲测试网卡真实改名待负责人验收。
