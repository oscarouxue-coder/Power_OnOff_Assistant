# DUT Telnet与WAN当前状态展示

## 目标

- Telnet配置页增加“查询当前Telnet”和“当前状态”展示区。
- WAN配置页复用“查询现有 WAN”的结果增加“当前状态”展示区。
- 四个Tab保持一致的只读查询、逐台展示和主日志语义。

## 实施步骤

1. core增加只读AccessCtrl规则解析和锁源TCP 23探测，不执行set/add。
2. 扩展状态查询service支持Telnet的网络准备、登录重试、session注销、停止和失败隔离。
3. 主程序接入Telnet异步查询；WAN查询结束时直接展示已有逐台连接快照。
4. UI为Telnet和WAN增加当前状态区，并在目标变化或配置执行后使旧状态失效。
5. 补充core/service/UI回归，更新文档并执行强制门禁。

## 验收边界

- Telnet查询只允许bbfdm.get、TCP 23探测和session注销，严禁隐式开启总开关、规则或新增规则。
- WAN不额外重复查询，只展示当前“查询现有 WAN”批次返回的每台连接摘要。
- 表格继续显示简短结果，完整路径、规则、连接和异常保留在当前状态区与主执行日志。
