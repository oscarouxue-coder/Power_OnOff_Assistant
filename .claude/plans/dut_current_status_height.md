# DUT 当前状态高度调整与持久化计划

## 目标

- 六个 DUT 配置 Tab 的“当前状态”显示区均支持拖动调整高度。
- 每个 Tab 独立保存自己的显示高度。
- 关闭 DUT 配置窗口后再次打开，自动恢复上次高度。
- 拖动、恢复历史高度或切换 Tab 时，底部目标加载提示和操作按钮栏必须始终完整可见。

## 实现

1. 在统一 `_build_current_status_area()` 中增加可拖动高度调节条，避免各 Tab 重复实现。
2. 将“已加载 N 台目标 DUT”提示行和按钮栏组成统一底部区域，按 `side=bottom` 放在 Tab 布局队列首位，先预留两者完整高度，再让状态区和目标表格分配剩余空间；同时按当前 Tab 和底部区域的实际屏幕位置动态收敛状态高度，不能只依赖固定最大行数或事后测量。
3. 使用独立本机状态文件 `~/.aouxue_dut_config.json` 保存六个 Tab 的高度；非法、损坏或不存在的文件安全回退默认高度。
4. 拖动结束与窗口销毁时保存，应用退出时也能保留最近一次调整结果。
5. 增加状态读写、范围收敛、统一拖动入口与关闭保存回归。
6. 在窗口首次显示、重新显示和 Tab 切换后重新校正当前页高度；如果历史高度会遮挡按钮，保存校正后的安全高度。

## 验证

- 主界面专项 unittest。
- `python scripts\verify_baseline.py`。
- `git diff --check`。
- Windows 桌面手动拖动六个 Tab，确认拖到最大时“已加载 N 台目标 DUT”提示及“刷新/查询/停止/执行/关闭”仍完整可见，并关闭/重开确认逐页恢复。
