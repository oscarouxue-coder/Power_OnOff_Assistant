# 开关机测试通道概览

## 目标

在主界面的“环境检查与开关机测试”卡片内展示可折叠的多通道进度概览，避免把运行轮次、重试和失败详情混入左侧通道配置区。

## 范围与不变量

- 总进度仍取所有已选通道均完成的最小轮次；不以平均完成量虚增进度。
- 增加每个已选通道的独立轮次、运行/重试/失败/完成状态，并在卡片内给出当前轮概况和仅含异常/落后通道的关注行。
- 左侧通道列表仅保留配置、选中和既有结果日志入口，不再以运行状态着色。
- 不改变旧 Start All、程控电源指令、版本预检、停止事件、确认提示、配置持久化或最终逐通道结果提示。
- 新增 UI 更新仍由编排器投递到 Tk 主线程；不从子进程直接操作 Tk。

## 实施与验证

1. 旧 Start All 适配层从现有每轮日志解析中回传已选通道的独立完成轮次与当前阶段；编排器安全投递主界面。
2. 主界面测试卡新增可折叠概览、当前轮摘要、关注行和可点击的通道小卡；单击后在卡内显示该通道详细信息。
3. 覆盖日志解析/回调、编排投递、主界面状态汇总与左侧配置区不再着色的回归；同步操作员说明、状态/验收边界和开发记录。
4. 在主源码目录运行开关机 service、编排和主界面专项测试、`python scripts/verify_baseline.py`、`git diff --check`；不构建 EXE、不连接或操作真实设备。
