# 全流程批量 ONU 注册

## 目标

让全流程的 ONU 注册子任务等待实际批次结果；操作员在 ONU 窗口预先查询并勾选多个未注册 ONU 后，系统为每个 PON 生成不重复的 ONU ID，先完成整批只读预检，再逐台下发、上线轮询和回读验证。

## 范围与不变量

- 保留 C300/C600 各自驱动、CLI、解析和显式源 IP；不合并命令。
- 注册仍串行，一台失败即停止后续，保留已成功配置且不自动回滚。
- C300 批量禁用“失败后删除离线 ONU 重试”；批量不自动 `write`。
- ONU 全流程仍由操作员确认，且必须等待注册或停止的最终结果，才能进入下一子任务。
- 仅把操作员事先在本次 OLT 查询中勾选的 SN 加入批次，不按查询返回顺序猜测样机目标。

## 实施

1. 新增批量请求构建模块：按选中顺序、每个 PON 独立分配 ID，拒绝重复 SN 与重复 PON/ID。
2. 扩展现有注册 service：先验证全批并完成全部预检，再按固定顺序逐台配置、上线和回读。
3. 将 ONU 发现列表改为原生 `Checkbutton` 多选；预览列出每台 SN、PON、ONU ID。
4. 为全流程新增 UI 线程桥接，注册完成、失败、取消和可选保存结束时回传结果。
5. 增加批量分配、预检无写入、失败停止和管道等待的自动化测试；同步操作说明、状态、验收边界和开发记录。

- `test_app.py`、`test_pipeline_orchestrator.py` 回归。
- `python scripts\verify_baseline.py`。
- Windows 源码版与 C300/C600 多台真实样机验证另行记录，自动化测试不替代现场结论。
