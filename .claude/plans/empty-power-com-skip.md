# 空程控电源 COM 跳过策略

## 目标

允许程控电源 COM 下拉框保存空值。空值时展示全部本机网卡，并让涉及程控电源的流程记录“跳过”后继续执行后续步骤。

## 范围

1. 配置存储保留空 COM，不回填默认端口。
2. 主界面空 COM 时展示所有识别网卡；已选 COM 时维持每 8 个 VLAN 的筛选。
3. 电源 service、并行升级协调器和全流程管道把空 COM 视为成功跳过。
4. 补单测、同步操作说明、状态页、验收基线和开发记录。

## 不改动

- 不改程控电源实际下发协议、通道帧和 VLAN 到串口映射。
- 不改 Tftp指令 与 Tftp Put 的传输边界。
