# 旧工具开关机日志降噪与轮次高亮

## 目标

- 新工具主执行日志中，旧工具“通道开始第 N 次测试”日志使用绿色字体。
- 精简旧工具无 GUI 业务转发到新工具的日志，但不影响旧工具执行、独立结果文件和错误定位。

## 实施边界

1. 不修改 `Auto_Power_On_Off_Tool.py` 及旧工具 `test_case/common/clients` 业务源码。
2. `show_signal*` 操作员日志继续转发；WARNING / ERROR 始终保留。
3. 旧 logger 的 INFO 只保留登录、连接、Ping、WiFi、重试、测试完成等关键结果，过滤配置路径、原始命令回显、串口状态等底层噪声。
4. 短时间内 logger 与 signal 的同级同文日志只显示一次。
5. 实际程控电源帧、子任务阶段日志和最终成功/失败不参与过滤。

## 验证

- 增加主窗口日志标签选择回归测试。
- 增加旧日志来源过滤、错误保留、短时去重和主流程转发回归测试。
- 执行 `python scripts\verify_baseline.py`。
