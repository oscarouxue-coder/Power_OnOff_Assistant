# 主界面开关机测试状态与停止控制

## 目标

- 在主界面“环境检查与开关机测试”卡片空白区域显示全流程运行状态。
- 将“停止”控制从全流程弹窗移动到主界面；当前按钮文案为“停止测试”。
- 二次确认后先启动后台线程，再隐藏全流程配置窗口；运行期间不得被主入口重新弹出。
- 继续复用全流程编排器的同一个停止事件，不改变各子任务原有安全停止边界。

## 状态

- 未运行：按钮禁用。
- 正在执行：按钮启用。
- 正在停止：按钮禁用，等待当前子任务安全退出；旧 Start All 子任务直接收到停止事件。
- 已完成 / 已停止 / 执行失败：按钮禁用。

## 验证

- 主界面存在状态文字和停止按钮，全流程弹窗不再创建停止按钮。
- 状态随开始、完成、失败、停止请求切换。
- 主界面停止按钮委派给当前 `PipelineWindow.request_stop()`。
- 按钮刚启用而后台编排器尚在创建时，停止请求仍会被记住并在编排器就绪后立即下发。
- 完成、部分失败或异常提示以主界面为父窗口，全流程配置窗口保持隐藏，下一轮再重新显示。
- 完成/失败回调必须通过主程序 `pipeline_ui_task_queue` 回到 Tk 主线程，不得从后台线程调用隐藏窗口的 `after()`。
- 主入口和停止按钮必须核对全流程线程真实状态；若后台已结束但主界面仍残留运行态，应自动恢复，禁止交替输出“仍在执行”和“没有正在执行”。
- 运行完整 `python scripts\verify_baseline.py`。
