# ONU 注册三步式界面重排

## 目标

- 保留当前 `1000x800` 默认和最小窗口尺寸以及现有 C300/C600 service、driver 和安全边界。
- 将现有按内容分类的分页改为按操作顺序组织：`查询 ONU → 配置业务 → 确认执行`。
- 消除 C600 查询时在“连接与发现”和“C600 参数”之间往返，以及预览后返回第一页才能执行的问题。

## UI 编排

- OLT 型号、OLT IP、源 IP、用户名、密码、登录测试及连接状态固定显示在分页上方。
- “1. 查询 ONU”包含 C600 条件显示的机框/槽位/PON、查询按钮、发现结果和选择操作。
- “2. 配置业务”按型号切换内容：C300 显示固定模板摘要和危险删除开关；C600 显示完整注册与业务参数。
- “3. 确认执行”显示目标/安全策略摘要和完整命令预览，并放置唯一的“开始注册”主按钮。
- 查询页提供“下一步：配置业务”，配置页提供“生成预览并进入下一步”，确认页提供“返回修改”。
- 查询/执行状态、停止和关闭在窗口底部持续可见。

## 交互约束

- C300 查询结果保持多选以及全选/清除；C600 仍严格单选，隐藏含义不符的“全选”。
- 未选择 ONU 时不能进入配置或生成预览；未生成有效预览时不能开始注册。
- 型号、连接、选择或业务参数发生变化后，旧预览失效，必须重新生成。
- 预览只生成命令、不连接 OLT；实际注册仍执行既有二次确认、冲突预检、首错停止和型号专属验证。

## 普通窗口布局修复

- 保留当前 `1000x800` 默认和最小尺寸，不要求操作员最大化窗口。
- 顶层内容使用固定七行 `grid`：标题、说明、连接区、Notebook、危险提示、状态栏、底部按钮。
- 仅 Notebook 所在行设置伸缩权重，底部提示、状态和“关闭/停止”始终预留高度。
- 命令预览文本框显式使用较小的初始行数，避免 Notebook 按 Tk Text 默认高度请求过多空间。

## 验证

- 更新 `tests/test_app.py`，覆盖三步 Tab、全局连接区、C300/C600 条件内容、步骤切换和预览失效。
- 运行主程序专项测试和 `python scripts/verify_baseline.py`。
- Windows 源码版目视确认 `1000x800` 普通窗口下三个步骤、底部状态和操作按钮完整可见，无需最大化。
