# 修复批量 ONU 目标 ID 输入覆盖

- 范围：修复逐台选择并填写 ONU ID 时，共用输入框最后值覆盖整批起始值的问题；在现有 UI 保存本次查询内各目标的输入，批量构建器优先采用显式目标 ID。
- 实施：保持现有窗口和入口；切换目标前收集当前输入，切回时恢复；重新查询清空临时映射；同 PON 手填重复 ID 拒绝生成预览，未单独填写的目标保留自动分配。
- 不变量：保留 C300/C600 独立命令、整批只读预检、确认、日志、停止和 write 边界；不连接真实 OLT，不构建 EXE。
- 验证：回归逐台填写 3/4、重复 ID、跨 PON、预览/确认/worker 参数一致与重新查询清理；运行完整 verify_baseline.py；同步操作说明、验收待办、项目状态和开发日志。
- 回退：仅回退本轮输入收集、批量构建器和对应测试/文档，不搬迁其它功能。
