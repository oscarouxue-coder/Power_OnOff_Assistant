# 批量参数表XPON SN格式优化

## 目标

- 自动生成的`XPON SN`固定为12位字符。
- `XPON SN`前4位由操作员输入，后8位为大写十六进制字符`0-9/A-F`。
- 同批XPON SN保持唯一；为兼容既有参数表，继续写入`GPON SN`列。
- 普通`SN`仅使用数字字符；可编辑数字前缀与随机数字后缀合计不得超过16位，默认配置生成16位，同批保持唯一。
- 不改变已验收的MAC、SSID和其它字段规则。

## 实施步骤

1. 在参数表生成核心增加固定XPON SN格式校验与唯一十六进制后缀生成。
2. 调整生成窗口的XPON SN前缀与字段提示，将后缀长度明确为仅控制普通SN。
3. 增加XPON SN及普通SN的长度、字符集、唯一性、非法前缀、越界和UI接线测试并加入强制基线。
4. 同步README、项目状态、验收基线和开发日志。
5. 执行专项测试与`python scripts/verify_baseline.py`。
