# DUT语音与TR069当前状态查询

## 目标

- 在DUT配置的“语音配置”和“TR069配置”Tab增加独立只读查询入口。
- 查询结果逐台展示；单台或全部目标参数一致时同步回填当前表单。
- 多台参数不一致时不使用任意一台覆盖表单，保留逐台状态与主日志供核对。
- 查询复用网卡状态预检、锁源IP、UBUS登录重试、停止/失败隔离和设备session注销。

## 实施步骤

1. 在core增加VoiceService与ManagementServer只读查询、兼容响应解析和完整状态日志。
2. 增加语音/TR069状态查询结果模型与批量service，覆盖网络准备、重试、注销和停止。
3. 在两个Tab增加查询按钮、当前状态展示区、结果回填和目标变化/配置后的失效提示。
4. 主程序接入异步查询、逐台结果、批次汇总及停止状态。
5. 补充core、service、UI/主程序回归，纳入强制基线并同步项目文档。

## 验收边界

- 查询仅执行 `bbfdm.get` 和登录session注销，不执行配置 `bbfdm.set`。
- 语音按当前选择的线路索引查询，展示账号、服务器、DTMF、SIP模式、DigitMap和5项编码。
- TR069展示ACS、周期Inform、HTTP连接请求和证书配置；“配置后手动Inform”是动作选项，不从设备状态勾选。
- 任何目标失败或状态不一致时不得自动用某一台参数覆盖批量表单。
- 自动化验证与真实ONT验收分开记录。
