# 串口原始日志逐行增加时间戳

## 目标

- 串口日志文件中的每一行都以 `YYYY-MM-DD_HH:MM:SS` 开头。
- 保留方向字段，完整格式为 `YYYY-MM-DD_HH:MM:SS RX/TX/STATE/ERROR 内容`。

## 实施边界

1. 时间戳只写入磁盘日志，不修改串口原始字节历史、界面事件文本或升级标记判断。
2. RX 数据按逻辑行缓冲；同一行被多个串口读取块拆开时先拼接，再添加一次时间戳。
3. 一个读取块包含多行时逐行添加时间戳。
4. 串口关闭、TX、STATE 或 ERROR 到来前，安全写出尚未换行的 RX 残留。
5. 文件名日期规则、串口参数、VLAN→COM 映射和原始串口收发保持不变。

## 验证

- 覆盖 CRLF、LF、跨块半行和关闭前末尾残留。
- 验证每个落盘行均以 `2026-08-08_19:12:10` 开头且内容不丢失、不重复。
- 将用例纳入强制基线并执行 `python scripts\verify_baseline.py`。
