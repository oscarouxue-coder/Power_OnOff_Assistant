## V1.2.4

- 正式开关机测试初始化仅对本次已勾选通道逐个断电，不再广播全通道断电，避免影响其它通道上的设备。Telnet 和 SSH 测试均采用此规则。
- 启动确认列出本次通道，执行日志显示目标通道、实际电源帧和下发结果。
- 初始化中停止或下发异常时终止，不继续启动测试，也不自动恢复已断电通道；失败通道续跑继续跳过初始化断电。
- 保留按需版本校验、检查更新、样机升级、串口日志和其它现有功能。

推荐下载 **LineCheckAssistant_portable.zip**，完整解压后使用；已有配套配置的用户可单独下载 **LineCheckAssistant.exe**。支持 Windows 10/11，首次运行建议使用管理员权限。

换版前请结束测试并退出旧程序，备份旧目录及 `Auto_power_on_off_tool/config`，将新版解压到另一个目录后迁移配置。新包配置已脱敏，不要用默认配置覆盖旧目录。

ZIP 校验文件为 **LineCheckAssistant_portable.zip.sha256.txt**，EXE 校验文件为 **LineCheckAssistant.exe.sha256.txt**。
