## V1.2.3

- 更新为精简便携包：EXE 约 17.23 MiB，完整便携 ZIP 约 16.93 MiB，保留现有功能和使用方式。
- 开关机开始前版本校验支持按需执行：当前测试方案“项目信息”中的**软件版本、内部软件版本、ONU 软件编译时间**全部留空并保存后，跳过开始前版本校验。
- 三项去除首尾空白后全部为空才跳过；项目名称不影响判断。只填写一项或两项时会提示补齐并阻止启动；全部填写时继续严格校验，版本不一致或查询失败均阻止启动。
- 失败通道“从失败轮次继续”使用相同规则，保留原配置核对及单通道剩余轮次恢复。
- 确认提示与主执行日志明确显示是否跳过版本校验；配置文件缺失、不可读或格式错误时明确报错。
- 修复 Python 3.9 环境下检查更新模型导致的源码启动兼容问题。

推荐下载 **LineCheckAssistant_portable.zip**，完整解压后使用；已有配套配置的用户可单独下载 **LineCheckAssistant.exe**。

换版前请结束测试并退出旧程序，备份旧目录及 `Auto_power_on_off_tool/config`，将新版解压到另一个目录后迁移配置。新包配置已脱敏，不要用默认配置覆盖旧目录。需要跳过版本校验时，请在当前选定方案中清空上述三项并保存。

ZIP 校验文件为 **LineCheckAssistant_portable.zip.sha256.txt**，EXE 校验文件为 **LineCheckAssistant.exe.sha256.txt**。
