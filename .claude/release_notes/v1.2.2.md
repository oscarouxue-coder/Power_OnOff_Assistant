## V1.2.2

- 新增网卡名称检查：选择非数字结尾网卡时，可选择接受或取消改名建议。
- 接受建议后可输入新名称，点击“确认修改”由软件完成 Windows 网卡重命名。
- 新名称尾号范围为 **2–254（非网关地址）**，例如 `VLAN101`、`以太网101`。
- 改名成功后自动刷新网卡、更新通道引用、PC 静态 IP 及相关目标预览，保留已有 COM 对应关系。
- 增加管理员权限、任务空闲、重名及结果核实检查，后台执行并防止重复提交。

推荐下载 **LineCheckAssistant_portable.zip**，完整解压后使用；已有配套配置的用户可单独下载 **LineCheckAssistant.exe**。

换版前请结束测试并退出旧程序，备份旧目录及 `Auto_power_on_off_tool/config`，将新版解压到另一个目录后迁移配置。新包配置已脱敏，不要用默认配置覆盖旧目录。

ZIP 校验文件为 **LineCheckAssistant_portable.zip.sha256.txt**，EXE 校验文件为 **LineCheckAssistant.exe.sha256.txt**。
